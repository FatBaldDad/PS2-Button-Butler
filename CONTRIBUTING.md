# Contributing

PS2-Button-Butler is currently a private-development project with a limited public repository.

## Contributions That Are Welcome

The public repo is open to:

- Public feedback
- Compatibility observations
- Documentation corrections
- Research references that are already public
- General feature suggestions

## Contributions That Are Not Currently Accepted

This repository is not accepting:

- Hardware design pull requests
- Firmware pull requests
- Touchscreen UI pull requests
- PCB layout pull requests
- Fork-based development
- Clone hardware designs
- Manufacturing files
- Installation method submissions
- Productized derivatives
- Alternative implementations based on private FBD work

Please keep all discussions and suggestions at a high level and avoid submitting private implementation details.
